Depois de baixar
  1. Coloque icon-512.png e icon-180.png na pasta icons/ do projeto (substituindo os que estão lá).
  2. Faça git add icons && git commit -m "Novo ícone" && git push — ou suba os dois arquivos pelo site do GitHub.
  3. O ícone da tela de início só troca depois de remover e adicionar o app de novo (o iOS guarda o antigo em cache).
